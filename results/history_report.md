# History report

Generated offline by `python main.py history`. Kyiv calendar days from 2025-10-04 to the map cutoff, 2026-10-10 22:03 Kyiv (that day is partial). Nothing after it is used: it is the untouched holdout (step 7).

A region is under alert when some part of it is: the union of oblast- and raion-level AIR alerts, 23 oblasts and Kyiv City. Overlapping records count once; a restart after an all-clear is a new start. Sources: the map snapshot for alerts that start before the splice (2026-09-12 00:00 Kyiv), alerts.in.ua from it (seam check in `data_report.md`).

**Red share** = minutes under a red record / minutes under alert, from the splice on: the map has no levels, so the first days of the reform (09-07 to 09-11) are unlabelled. History keeps each record's final level (yellow → red is an in-place update), so a record that turned red counts as red for its whole length: the red share is an upper bound.
